# agents

Agent skills, maybe other stuff later

## Skills

| Skill                  | Description                                                        |
| ---------------------- | ------------------------------------------------------------------ |
| `caveman`              | Ultra-compressed communication mode.                               |
| `code-review`          | Review changes against standards and spec.                         |
| `defuddle`             | Extract clean markdown from web pages.                             |
| `domain-modeling`      | Build and sharpen a project's domain model.                        |
| `grill-me`             | A relentless interview to sharpen a plan or design.                |
| `grill-with-docs`      | Relentless interview that creates docs as you go.                  |
| `grilling`             | Grill the user relentlessly about a plan or design.                |
| `implement`            | Implement work from a spec or tickets.                             |
| `json-canvas`          | Create and edit JSON Canvas files.                                 |
| `obsidian-bases`       | Create and edit Obsidian Bases.                                    |
| `obsidian-cli`         | Interact with Obsidian vaults via CLI.                             |
| `obsidian-markdown`    | Create and edit Obsidian Flavored Markdown.                        |
| `prototype`            | Build throwaway prototypes for design questions.                   |
| `setup-agent-skills`   | Configure GitHub or local markdown ticket tracking and agent docs. |
| `tdd`                  | Use red-green-refactor test-driven development.                    |
| `teach`                | Teach a skill or concept in a stateful workspace.                  |
| `to-tickets`           | Break a plan, spec, or PRD into tickets.                           |
| `to-spec`              | Turn current conversation into a spec.                             |
| `writing-great-skills` | Reference for writing and editing predictable skills.              |
